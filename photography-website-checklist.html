Can a client enquire from your portfolio in one minute?

Open your photography site on your phone using mobile data. Start on the gallery page a potential client would find in search. Set a one-minute timer and follow the route from seeing your work to sending a test enquiry.

1. Show the next step next to the work

On a wedding gallery, try a button labelled “Check wedding availability”. On a portrait gallery, try “Ask about a portrait session”. Check whether a visitor can find the link without scrolling through the whole gallery.

2. Check how the first photo loads

Reload the gallery on mobile data. If the main photo takes time to appear, compare the original with a resized WebP or JPEG and check how each looks on a phone. Load the first photo promptly and defer gallery images farther down the page.

3. Answer the questions that affect an enquiry

Tell visitors which area you serve, which sessions you offer and what information helps you check availability. If you show a starting price, say what the package includes.

4. Submit your own enquiry

Try the form with one thumb. Check that labels stay visible, required fields make sense and errors tell you how to fix them. Send a clearly marked test to your own inbox and confirm the page shows that it arrived.

5. Change one thing and repeat the test

Write down the page, what you observed and one change to try. For example, “Wedding gallery · booking link below 30 photos · add the same link below the gallery introduction.” Repeat the one-minute test on the same phone after publishing.
